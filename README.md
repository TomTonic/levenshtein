levenshtein
===========

An implementation of the Levenshtein algorithm in Go forked from [texttheater/golang-levenshtein](https://github.com/texttheater/golang-levenshtein). Provides edit distances,
edit scripts and ratios for strings (slices of runes).

Installation
------------

    $ go get github.com/TomTonic/levenshtein

Documentation
-------------

The documentation can be viewed online here:
https://godoc.org/github.com/texttheater/golang-levenshtein/levenshtein
